# Toolblox 0.2.0 beta
*September 23, 2026 · first public beta*

## Accounts
- Sign in through Roblox's own login page. Your password never reaches Toolblox.
- Sessions are kept in Windows Credential Manager, never in a plain file.
- Sort, reorder, and add notes to accounts, then join any of them into a place.
- Run several Roblox clients at once.
- Auto-rejoin brings an account back when it leaves a game.

## App
- Dashboard, Accounts, Widgets, and Settings pages, with a resizable sidebar.
- Runs in the system tray and can start when you sign in to Windows.
- Checks for a verified update every time it starts, so you're always on the latest version.
- Brings over accounts from the earlier version of Toolblox.

## Widgets
- The groundwork for widgets: signed packages, permissions, and error boundaries that keep a broken widget from taking down the app.
