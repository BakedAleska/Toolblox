toolblox_lib

Module logs 

Source
Expand description

Rotating, redacted log file shared by the host, the interface, and widgets.

Records go through the log facade. Toolblox’s own records are kept from Info up (Debug in debug builds); other crates, such as Tauri and its plugins, from Warn up. Every line is redacted before it’s written, so cookies, tickets, authorization headers, and launch URLs never reach the file, whoever logged them.

The file is logs/toolblox.log in the data folder. It rotates at 1 MB and keeps three older files, toolblox.log.1 through toolblox.log.3.
