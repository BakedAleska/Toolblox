) -> Result<bool, String>
Expand description

Joins each account at place_id when given, otherwise at its own place or the default place. A player target follows that player, and fails for any account that can see they aren’t in a game.

progress is called with the number of the account being joined and the total. Returns false when cancel_join stopped the join before every account was launched.
