Module multi_instance 

Source
Expand description

Running several Roblox clients at once.

On Windows, the bundled audited helper closes Roblox’s singleton handles. On macOS, Roblox’s single-instance semaphore name is removed and the player is started directly, because Launch Services refuses a second instance of a bundle with LSMultipleInstancesProhibited. The semaphore was identified by multi-roblox-macos and rororo-mac.
