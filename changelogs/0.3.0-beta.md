# Toolblox 0.3.0 beta
*October 15, 2026*

## New
- **macOS.** One app for Apple silicon and Intel Macs, with multiple Roblox clients.
- **Custom themes.** Pick colors for light and dark mode, or import a theme as CSS. Safe mode turns a theme off.
- **Account search**, with filters and suggestions.
- **Diagnostic log** in Settings, with sign-in data removed, to help report problems.
- **Your commitments, on the dashboard:** free and open source, no injection, and your data stays on this device.

## Changes
- Recent places keep only places Roblox confirms exist, and you can remove them.
- Hover an account's name to see its user ID.
- The account toolbar sits under the page title, and menus and dialogs animate.
- Settings is reorganized.
- The update button is gone, because Toolblox already updates every time it starts.
- 0.2.0 data moves to the new data folder automatically.

## Website
- A new toolblox.dev with downloads for Windows and macOS, a privacy policy, and widget docs.
