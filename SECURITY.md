# Security

The security policy, including how to verify a download, is published at
[toolblox.dev/legal](https://toolblox.dev/legal/#security).

## Report a vulnerability

Don't open a public issue for an unpatched vulnerability involving sessions, updates, widget
isolation, or running code. Contact the repository owner privately through GitHub. Include the
affected version, platform, steps to reproduce, and expected impact. Remove Roblox sessions,
authentication tickets, and personal data from every report.
