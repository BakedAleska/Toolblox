Module roblox_files 

Source
Expand description

Advanced settings that write configuration files Roblox reads. Each is off by default, and this is the only place Toolblox writes Roblox’s files. None of them injects code or touches Roblox’s memory.

  • FastFlags. Roblox reads ClientSettings/ClientAppSettings.json next to its player when a client starts. Toolblox writes it before launches, because a Roblox update installs the player in a new folder. Turning FastFlags off, or launching in safe mode, deletes it.
  • Client settings. Roblox keeps its in-game settings in GlobalBasicSettings_<n>.xml, shared by every account. Toolblox sets the frame rate cap, graphics quality, and fullscreen values in it before launches. Roblox keeps the last values written after the setting turns off, and a client that exits saves its own values.
