# Toolblox 0.3.2 beta
*Unreleased*

## Performance
- **Tile windows:** arrange every open Roblox window in a grid, at full screen, medium, or small size. *(Windows)*
- **Client priority:** run alts at below normal or low priority, as a default or per account.
- **CPU cores per client:** spread clients across your CPU. *(Windows)*

## Advanced settings
Off by default, behind a confirmation in Settings. They write configuration files Roblox reads when it starts, and never touch Roblox's code or memory.
- **FastFlags**, as a default and per account.
- **Client settings:** frame rate cap (up to 240), graphics quality, and window size *(Windows)*, as a default and per account.
- Accounts with different settings launch one at a time, so each client starts with its own.

## Accounts
- **Expired sessions** are detected and marked. Select **Sign in again** to fix one. Joining skips them and tells you which.
