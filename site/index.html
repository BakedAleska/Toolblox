Toolblox

A local-first desktop app for managing and launching Roblox accounts. Sessions stay in the operating system's credential store, and no telemetry is collected.

Windows 10 and 11

Download Toolblox for Windows
  1. Open Toolblox-Setup.exe once the download finishes.
  2. If Windows shows “Windows protected your PC”, select More info, then Run anyway.
  3. Follow the setup steps. Toolblox keeps itself up to date after that.

The installer is the only download needed. The source code archives on GitHub are for developers and don't contain the app.
