# Toolblox 0.4.1 beta
*Unreleased*

## New

### Pinned accounts
- Select the star on an account to pin it to the dashboard, ready to join. Pinned accounts replace **Recently played**.
- Pinned accounts are listed first in Mini mode.
- Select a filled star to unpin the account.

### Place search
- Type a game name in any place field and pick it from the list. Game links and place IDs still work.
- **Search games…** in the default place menu, or double-clicking the default place, opens a full search page.
- Each result shows players online, visits, favorites, likes, last update, creator, genre, maturity, and price when a game costs Robux.
- Press **Enter** to use the top result.
- **Join** with no place set opens the search page.

### Custom CSS page
- **Custom CSS** at the top right of **Settings → Themes** opens custom CSS on its own page, with more room to edit.

### Log page
- **View** in **Settings → General → Diagnostics** opens the full log on its own page, newest first, with **Refresh**, **Copy**, and **Open folder**.

### Animation settings
- **Settings → General → Show animations** turns animations on or off. Loading spinners still turn.
- **Settings → General → Ignore system reduced motion** plays full animations even when Windows or macOS asks for reduced motion.

## Changes

### Dashboard
- **Redesigned.** Issues show as cards with an icon and a color for how serious they are: expired sessions, widgets that failed to load, unavailable status, a missing default place, and widget updates.
- Select a card to go where it can be fixed.

### Accounts
- **Simpler search:** it matches username, display name, and notes. The `#game:`, `#last:`, and `#note:` filters are removed.
- **Selecting accounts:** double-click an account, then click others to add them. The select button is removed.
- **Roblox Studio** shows as **Studio - *place***, as on roblox.com, with a hammer instead of the green dot.
- Hovering an account's name no longer shows its user ID.

### Widgets
- **Redesigned cards** show each widget's logo with a matching banner.
- Widgets can set their own banner image.
- The catalogue sits below installed widgets.

### Look and feel
- **Theme**, **Snap to default aspect ratio**, and **Mini mode** sit at the top right of every page.
- **Mini mode** opens only from its button at the top right. It's no longer in **Settings → General**.
- **Large windows** fill with more columns.
- Clearer selected options, switches, checkboxes, and keyboard focus.
- **Less text:** settings, empty pages, and dialogs no longer show a description under their titles.
- **macOS:** the menu bar icon is a one-color toolbox that matches the other menu bar icons in light and dark mode.
- **macOS:** the Dock and app icon sit on a white rounded square, like other Mac apps.
- Error notifications stay on screen until closed. Other notifications still close on their own.
- Menus opened from a button have a small arrow pointing at that button.

### Wording
- Text throughout the app is clearer and more consistent. Error messages say what went wrong and suggest a next step, and labels such as **View all**, **Show game names**, and the beta survey use more precise wording.

### Removed
- The sidebar's GitHub button.
- **Restart without widgets** in the tray menu.
- **Client priority**, **CPU cores per client**, and **Tile windows**, including the account menu's **Priority** option.

---

## Fixes
- **Place links** work without `https://`, from any roblox.com page, and with a `placeId=` in the link.
- A typo in the default place no longer clears it.
- **Join** shows a spinner until Roblox opens, so an account can't be launched twice by accident. This includes Mini mode.
- Theme color pickers no longer lag while dragging.

---

## Beta survey
- A short, optional survey opens once after this update: a 1–5 rating and a comment box.
- Closing it without answering shows one rating-only follow-up. It doesn't appear again.
- Reopen it any time from the clipboard button at the top right of every page.
- Nothing is sent unless you press **Send**. Answers go to the developer through the Toolblox Discord bot.
