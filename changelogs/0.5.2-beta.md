# Toolblox 0.5.2 beta
*November 17, 2026*

## New

### Account tags
- Tag accounts to tell them apart, such as **Main**, **Trading**, or **Alts**. Each tag has a name and a color.
- Tags show at the end of an account's note. Without a note, they take its place after a **…** you can still select to write one.
- Hover an account and select the tag button beside its name to add a tag. Type a name and press **Enter** to create one, or check an existing tag. Hover a tag in that menu and select the trash button to delete it from every account. Deleting a tag keeps its accounts.
- Select a tag on an account to rename it, change its color, or remove it from that account.
- Search on **Accounts** also finds accounts by tag.
- Tag colors can be changed in a custom theme, under **Tags**.

### Notes and tags for each game
- While the default destination is a game, every account shows its note and tags for that game. Switch the default destination to switch games. Each game starts with an empty note and no tags.
- With no default destination, or one that follows a player, accounts show their general note and tags, including the notes you had before.
- Select **No default** in the destination picker to go back to the general note and tags.

## Changes

### Joining friends
- Selecting an online friend on the dashboard now always joins as the **Continue as** account, whichever accounts' friends are listed.
- If that account isn't friends with them, it sends them a friend request instead. The message offers a **Join as** button for an account that is their friend.
