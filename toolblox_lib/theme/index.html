Module theme 

Source
Expand description

The custom theme, which is custom CSS. It’s applied after the theme tokens in src/theme.css, so a theme changes colors and radii by setting those tokens.

The saved theme.css and exported theme files are the same plain CSS. Nothing in a theme may load from outside this device: it can reference only embedded data URLs, so a shared theme can’t reveal anything to a remote server. The CSS editor can name local files, which are embedded before the theme is saved.
